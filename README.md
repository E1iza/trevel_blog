# Блог о путешествиях

## Описание проекта
Frontend-приложение для блога о путешествиях с возможностью публикации записей и фотографий.

## Технологический стек
- **React** (библиотека UI)
- **Redux Toolkit** (менеджмент состояния)
- **Vite** (сборка проекта)
- **Formik + Yup** (формы и валидация)
- **Tailwind CSS** (стилизация)

## Функционал
✅ CRUD операции с постами  
✅ Адаптивный интерфейс  
✅ Валидация форм

## Установка
```bash
git clone https://github.com/E1iza/trevel_blog.git
cd trevel_blog
